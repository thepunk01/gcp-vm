      添加云账号

      GCP 控制台 → IAM → 服务账号 → 创建 JSON 密钥。角色：Compute Admin；使用「执行命令」还需要 Service Account User。

      在 Azure Cloud Shell 执行（把订阅 ID 换成你的）：
      az ad sp create-for-rbac --name gcpvm --role Contributor --scopes /subscriptions/订阅ID
      把输出的 JSON 粘贴到下面，会自动填好；订阅 ID 在门户「订阅」页查看。
