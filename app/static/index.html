GCP VM 管理

防火墙规则

规则作用于该项目整个 VPC 网络。GCP 默认只放行 SSH 22、RDP 3389 和 ICMP，其余端口需要在这里放行。删除 default-allow-ssh 会导致面板「SSH 执行」无法连接。

名称网络方向动作协议 / 端口来源 / 目标 IP作用于优先级

GCP 服务账号

检测方式

主动上报探针（推荐，探针设备不需要公网 IP）

适合家里的路由器（OpenWrt / iStoreOS）、NAS、树莓派等。探针定时主动连接本面板领取任务并上报结果。添加后点「安装命令」获取部署方法，然后保存设置。



            
监听模式探针（探针需要公网 IP）

            
在一台有公网 IP 的国内机器上运行 probe/probe.py，填入地址与令牌。可添加多个，所有探针按成功率综合判断。
